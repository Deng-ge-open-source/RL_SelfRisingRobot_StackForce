# SelfRising 90S - 四件打印结构 / Four-part structure

本版本包含四个打印分件：底座、底盖、中间连杆、上部连杆。
以毫米为单位、100% 比例打印 01-04 号分件。整机参考仅用于查看装配位置，含四个结构件与两只舵机参考几何。

This version contains four printable parts: base, bottom cover, middle link and upper link.
Print parts 01-04 in millimetres at 100% scale. The assembled reference contains four structural parts and two servo reference geometries.
